<h2 aline="center"> ​A comprehensive, all-in-one Python script demonstrating the full range of mathematical capabilities in Python—from basic arithmetic to advanced constants and trigonometric functions.</h2> <br>
​<h3 aline="center">🚀 Overview</h3> <br>
​This repository contains a single, well-documented Python program  that serves as a cheat sheet for anyone looking to master math in Python. Whether you are building a calculator or a data science model, this script covers the essentials.
​🛠 Features Included <br>
​The program is divided into four main categories: <br>
​1. Basic Arithmetic <br>
​Covers the standard operators you use every day: <br>
​Addition (+), Subtraction (-) <br>
​Multiplication (*), Division (/) <br>
​Floor Division (//) - Rounds down to the nearest integer. <br>
​Modulus (%) - Returns the remainder. <br>
​Exponentiation (**) - Power functions. <br>
​2. Built-in Math Functions <br>
​Standard Python functions that don't require external imports: <br>
​abs(): Absolute value. <br>
​round(): Rounding to specific decimal places. <br>
​pow(): Alternative to the power operator. <br>
​3. The math Module (Advanced) <br>
​Deep dive into the standard library for scientific calculations: <br>
​Constants: \pi (Pi), e (Euler's number), and \tau (Tau). <br>
​Roots & Logs: sqrt(), isqrt(), log(), log10(). <br>
​Trigonometry: sin(), cos(), tan() (radians and degrees). <br>
​Rounding: ceil() (up) and floor() (down). <br>
​4. Comparison & Logic <br>
​Greater than/Less than logic. <br>
​Checking for NaN (Not a Number) or inf (Infinity) <br>
